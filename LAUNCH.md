# Launch & distribution guide

How this skill spreads — and the philosophy behind it. This skill gives real value for
free (strategy + copywriting run on Claude's reasoning alone), and every *execution*
step routes through the [LinkedNav](https://www.linkednav.com?utm_source=github&utm_campaign=outreach-os)
MCP. Open orchestration, hosted engine.

## The honesty line

> The skill is open source (MIT — read every prompt). The engine it calls to actually
> run outreach is LinkedNav, over the open Model Context Protocol. Open orchestration,
> hosted engine. Strategy + copy work with nothing connected.

Use this whenever someone asks "is this really open source if execution needs a key?"
It's the same model as any open-source app that calls an API.
